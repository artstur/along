# 联网推荐在原目标内展示

主分类：ui / client；依赖：Agent 仓联网研究 Worker、来源凭据与推荐消息协议（独立 PR）。

## 目标与验收

已有徒步任务到期或用户通过原目标聊天询问时，真实 Worker 检索当下官方开放、预约、天气与路线资料，将有来源的少量方案同步到原目标。用户能看到推荐卡、展开具体条件和未知项、点开来源，再通过同一目标聊天反馈。原五项任务、睡眠/瑜伽提醒、配对和健康授权保留。旧消息与旧快照继续读取。

## 范围和实现

复用 message 同步的可选 recommendation v1 字段；前端先校验结构、来源引用及公共 HTTPS 链接，再将纯文本内容转义渲染。卡片位于原目标动态任务附近和原对话结果中，使用现有卡片/原生 details，不新增全局入口或配置。显示检索时间、匹配理由、时间窗口、条件、缺失项和来源；过期结果保留但清楚要求重新核实，不呈现为当前可执行推荐。结果通知复用现有推荐就绪事件，点击进入包含对应卡的目标对话。反馈仍用原聊天，不直接修改目标或标记徒步完成。

iOS 将用户主动点击的合法外部 HTTPS 来源交给系统浏览器；不允许页面自动跳转、内部地址、凭据 URL 或其他 scheme。推荐协议无效时只隐藏该扩展并保留旧对话，避免阻断目标/任务同步。

## 验证

覆盖真实同步存储和离线恢复、旧消息兼容、错误结构及引用拒绝、地址/HTML 注入、过期/风险展示、通知定位和同目标反馈。运行 npm run check/build，核对 web、dist、iOS内置和最终签名包。浏览器窄屏验收后从合并主线签名覆盖安装原 iPhone，记录实际来源打开与推荐详情观测。后台新结果远程送达仍取决于已有 APNs 条件，不用本轮前台本地通知替代验收。

开发回归：npm run check 389/389；npm run build 19资源。新增覆盖来源/HTML注入、过期与风险收紧、扩展失败保留旧消息、离线重开和原任务反馈、推荐通知定位。上机与真实Worker验收待集成后补记。

独立审查发现资料跨有效期但同步无新消息时未刷新。已先失败复现，再将过期状态检查接入原3秒前台同步与热恢复入口，仅状态改变时重绘并保留草稿；不依赖网络成功返回。

独立审查另发现推荐通知先于消息同步时误回旧任务并确认打开。先失败回归覆盖离线、空同步与延迟结果；现在保留原通知路由，待同目标同事件结果可见后定位并确认，旧的纯文本推荐通知也仍可回对话。

手机按用户安排断开，安装/前台验收延至恢复连接后。旧App可能已经确认消息但未保留推荐扩展；首次升级使用持久outbox做一次兼容重放，保持原游标下界、任务、草稿及身份，不重复触发已见结果通知，断网或分页中断可继续。过期来源继续可见地标注，不能声称旧App会通过同步自动获得新界面。

真实来源验收发现检索服务的 publishedAt 与官方网页正文日期不一致。来源元数据仅显示为「日期线索（待核实）」，不能称为已核实的发布日期；检索时间仍使用本地实际取证时间。

## 天气到期单独提示（2026-11-17）

主分类：ui/client；依赖：已合并 PR24 的 recommendation v1，PR25 的后台推荐呈现；无上游代码变更。用户可观察验收：只有天气依据过期时，卡片显示「天气待更新」，路线标题、事实、来源和反馈入口仍可用，不把整个方案标成「资料已过期」。

现象：来源最早到期时间被用作整卡状态。天气与警报来源短时到期后，仍有效的路线候选也被整卡过期提示覆盖。现有 v1 通过 checks.kind 与 sourceIds 已能识别天气依据，不按标题、URL 或 TTL 猜测类型，不改 Agent 校验和资料有效期。

实现：按 weather 检查的来源引用识别天气（含警报）资料；同一来源也用于 access 检查时仍保留开放依据到期限制。天气单独到期时显示「天气待更新」，相应候选保留供比较、不可继续显示「适合考虑」；已知风险的「暂不建议」不因到期被覆盖。过期检查正文明确是上次核对结果，来源仍可打开。非天气来源到期、无法归类或无来源的整体验证期限到期时维持重新核实提示。按候选各自依据提示，不让一条路线过期覆盖另一条路线。

前台轮询、离线和 pageshow 继续重新计算，每条来源状态变化都参与重绘，覆盖先天气后开放资料到期的连续过程；保留未发送草稿。用隔离合成推荐进行测试和浏览器验收，不代发正式目标消息，不改个人目标、任务或配对。Web v69 / iPhone Build60。

回归：天气单独到期、不同路线天气到期、天气/开放先后到期、显式风险、来源共用与无法归类、无来源旧结果，以及离线恢复、来源打开和同任务反馈。运行 npm run check/build、两端资源核对、独立只读复核；合并主线后签名覆盖原 iPhone，并分别记录安装/启动和实际页面验收。

独立复核补充：同一天气来源可被另一候选通过 facts/sourceIds 复用，候选状态须检查其全部引用，过期事实标为「上次资料（待更新）」。已固定输入先失败复现，再修复通过；不让自己天气检查较新的候选掩盖共用的旧依据。

验证结果：首次全量基线395项通过（新增复现用例在随后写入时单独失败）；修复后全量400项通过，独审补充后定向40项通过，最终全量另核。原整卡过期、跨候选共用来源和离线连续到期均实跑先红后绿；分别回退推荐呈现和重绘签名，用例再次失败。独立只读复核最终 PASS。真实浏览器393px窄屏已观察「天气待更新，路线候选保留」，实际展开路线读取事实和上次天气提示，再切换开放资料到期确认仍需核实。合成页面不连接个人数据，真机观察和公开部署另记台账。
