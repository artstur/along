## Device wire

Existing publish summary unchanged; optional private `history` included in same atomic grant/sequence/event/digest. No history in status/browser/source-event metadata. History exact shape `{version:1,windowStart,windowEnd,streams,fills,bills}`. ISO8601 fixed begin/end, last three calendar months, at most90days; pagination uses generation timestamp ts, not fillTime. Streams exactly six fills instTypes SPOT/MARGIN/SWAP/FUTURES/OPTION/EVENTS and one bills instType ALL. Each `{kind,instType,status,reason,pages}`; status complete/truncated/unavailable, reason none/page_limit/api_unavailable. A failed regional endpoint is unavailable, never empty-complete. Page100, fills max5pages/type, bills max20pages;450ms spacing. Dedup billId as string; cursor strictly advances older, repeated cursor/malformed response cannot claim complete. Maximum3000fills/2000bills, history JSON2MiB.

Fill exact string keys `billId,tradeId,ordId,instType,instId,side,posSide,fillPx,fillSz,fillPnl,fee,feeCcy,ts,tag`. Bill keys `billId,instType,instId,type,subType,ccy,pnl,fee,balChg,sz,px,ts`. Numeric strings preserve empty optional fields (not zero); IDs/tags/currencies bounded safe ASCII, ts13digit ms within declared window. Raw provider blobs/unknown fields rejected. No caller-selected URL/method; add only fixed GET fills-history/bills-archive to existing native allowlist. Exact read_only check and Keychain identity unchanged. Summary survives historical API partial failure and existing v1 records migrate without credential reentry.

Shared DeviceEventQueue keeps64KiB default for HealthKit; OKX explicitly opts into max event2.2MiB and pending total8MiB. Do not discard unacknowledged events. Protected state/Host caches match bounded size. Native route alone raises body limit; generic routes stay32KiB. Existing receipt/CAS/revoke/pairing protections unchanged. iPhone opportunities, not always-on background promise.

## Narrow Agent read

New capability `trading_history` only when admitted validated history exists; existing trading_account_summary remains compatible. Capabilities are metadata only, never raw rows. History content is part of source digest/version; adding/removing capability must publish actual updated fact. Existing freshness/grant/goal/task/occurrence/revocation rules apply. Private Host retains raw rows, computes deterministic exact decimal report. Ready history read uses history.windowEnd observation time.

Report: `{version:1,windowStart,windowEnd,coverage,totals,groups,sampleFills,sampleBills,limitations}`. `coverage:{complete,streams,fillCount,billCount,matchedFillCount,unmatchedFillCount,groupsTruncated}`. `totals:{fills,orders,bills,buys,sells}` integer counts. `groups:{fills:[{instType,instId,feeCcy,fillCount,orderCount,buyCount,sellCount,feeCashflow,missingValues}],bills:[{instType,instId,ccy,billCount,tradePnl,tradeFee,tradeNet,fundingCashflow,otherCashflow,otherCount,missingValues}]}`. Monetary fields exact decimal strings or null if missing source values make that total unknown. max100groups each and10example rows each; group overflow is explicit partial. Examples are normalized private records. Limitations fixed safe strings, including incomplete stream/data, no currency conversion, no account-wide ROI/Sharpe/win rate/drawdown, no spot cost basis, no user strategy mapping. Raw IDs/tags never go into public search/notifications/general logs.

Fill fees group by feeCcy; bills group by ccy. Ordinary trade(type2) pnl+fee only derivative SWAP/FUTURES/OPTION, labeled observed ordinary trading components, not full net profit. Funding(type8) balChg separate; do not also add its pnl. Other type cashflows (transfer/interest/liquidation/settlement/ADL) separate, not profit. Fills fees and bills fees are alternative records, never add together. No cross-currency sum. No position-history lifetime PnL/posId trade count. Agent reads actual report/coverage, interprets facts and asks user strategy rules if absent; instrument/tag clustering is not invented strategy identity. Explicit stale/missing remains durable wait, no polling model loop. New history capability should cause one bounded legacy goal review, preserving manual task meaning and old plans, no injected user chat.
